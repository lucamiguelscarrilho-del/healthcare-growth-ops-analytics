![Status](https://img.shields.io/badge/Status-In%20Progress-yellow?style=flat-square)
![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)
![SQL](https://img.shields.io/badge/SQL-4479A1?style=flat-square&logo=mysql&logoColor=white)

Simulated healthcare growth analytics system focused on user behavior, funnel performance, and retention optimization.

- Built SQL queries to analyze user funnel conversion and drop-off points  
- Performed exploratory data analysis using Python  
- Defined KPIs: conversion rate, retention rate, and acquisition efficiency  
- Translated data into actionable growth recommendations  

**Outcome:** Identified key funnel friction points and proposed optimization strategies for user conversion improvement.
